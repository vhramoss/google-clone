# Google Clone

This project is a front-end implementation inspired by the Google search interface, developed as part of the CS50 Web Programming course.

## Features

* Standard Google Search page
* Google Image Search
* Advanced Search with multiple filters
* "I'm Feeling Lucky" functionality
* Navigation between pages

## Technologies Used

* HTML5
* CSS3

## Project Structure

```
google-clone/
│
├── index.html        # Main search page
├── images.html       # Google Images search
├── advanced.html     # Advanced search page
└── styles.css        # Styling
```

## How It Works

This project uses Google’s search endpoints through HTML forms:

* Standard search: https://www.google.com/search?q=
* Image search: parameter `tbm=isch`
* Advanced search: parameters such as `as_q`, `as_epq`, `as_oq`, and `as_eq`
